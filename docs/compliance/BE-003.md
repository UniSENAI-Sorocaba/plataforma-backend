## Warnings/justifications

1. A tag oficial não está publicada. O SHA pode ser consultado, mas uma cópia
   local não substitui a validação tag → SHA exigida por ADR-008.
2. Os quatro contratos exigidos na issue não existem na baseline fixada. Não
   foram inventados endpoints, paginação, headers ou regras funcionais para
   ocultar essa dependência.
3. O formato operacional nativo do Actuator é preservado. A ausência de erro
   RFC 9457 em suas probes está documentada; não representa dispensa para APIs
   de domínio futuras.
4. As SPECs funcionais permanecem Draft. A integração dos contratos globais,
   a coordenação com QA-010 e a revisão humana continuam pendentes.
